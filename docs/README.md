# WireSkein の企画文書

WireSkein は、ロジックアナライザなどの観測記録から必要な情報を取り出し、後工程の分析へ渡すためのワークベンチを目指す。出発点は、既存ツールの入力・拡張・出力の制約を補うために、個別の解析・再集計スクリプトを繰り返し作っていたことにある。

特に、次の負担を減らしたい。

- **使える機材と拡張方法の制約。** 使いやすいアプリが専用機材を前提としていたり、未対応機器を追加するための本体変更やビルド環境の準備に大きな手間がかかったりする。
- **再利用や配布の制約。** 技術的には拡張できても、ライセンス条件が想定する組み込みや変更版の配布方法に合わず、利用範囲が限られる場合がある。
- **出力を使うための作業。** 必要な項目が欠ける、形式が後工程で扱いにくい、不要な情報まで大量に出る、といった理由で、抽出・変換・再集計を個別に実装している。全量を人や AI が読み解く負担や、トークン消費も大きい。

手近な機器の記録を取り込み、利用者が入力アダプタや独自プロトコルの解析を容易に追加できる、MIT ライセンスの基盤としたい。簡単なビルドを含め、追加と保守の負担が小さい方法を目指す。デジタル信号、アナログ波形、低頻度の測定値を扱い、必要なチャンネル・区間・項目を後工程が使いやすい構造で出力する。未解釈部分や除外箇所、元データとの対応を保ち、短い結果から詳細を確認し、同じ条件で分析を再現できることを重視する。
