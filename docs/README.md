# WireSkein の企画文書

製品の方向性、目指す振る舞い、具体的な利用場面をまとめる。実装方式と最初の版の機能範囲は、実データで検証してから決める。

| 文書 | 読む目的 |
| --- | --- |
| [ビジョンとコアの方向性](project-concept.ja.md) | 解決したい課題、提供する価値、コアと周辺の境界を理解する |
| [ワークベンチの使い方と共通概念](workbench-model.ja.md) | プロジェクト、マーカー、処理の再利用、出力と再現性がどう役立つかを具体例で理解する |
| [ユースケースと得たい結果](use-cases.ja.md) | 実際の調査で何を受け取り、次に何を調べられるとよいかを確認する |
| [今後の検証計画](next-plan.ja.md) | 未採用の方式・技術案と、それを判断するための実験を確認する |

最初の3文書は現在の方向性を表す。具体例に含まれる機器・プロトコル・形式は、その製品への依存や初期対応を約束するものではない。名称、記法、評価方法、保存方式などの詳細は検証計画で扱う。
